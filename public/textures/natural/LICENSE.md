# Moonhollow natural surface textures

These photographs are by **Poly Haven** and its contributing artists. The
assets are released under [CC0 1.0](https://polyhaven.com/license), and are
stored locally in this repository. MyVerse does not call an asset API at runtime.

| Surface | Source asset | Included maps |
| --- | --- | --- |
| Ground | [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02) | Diffuse, OpenGL normal, roughness |
| Cliffs and rocks | [Rock Face 03](https://polyhaven.com/a/rock_face_03) | Diffuse, OpenGL normal, roughness |
| Masonry | [Stone Wall 02](https://polyhaven.com/a/stone_wall_02) | Diffuse, OpenGL normal, roughness |
| Tree bark | [Pine Bark](https://polyhaven.com/a/pine_bark) | Diffuse, OpenGL normal, roughness |

All maps are the original 1K JPEG downloads. The 12 files total 9,377,462 bytes.
`sources.json` records the original download URLs, byte sizes and MD5 checksums,
verified when imported. Keep this file and the manifest with the assets.

Only colour maps use sRGB. Normal and roughness maps are linear data. These
files are loaded only by the 3D world; procedural materials remain available
when a file fails to load. Shared photograph textures belong to the world and
are released when the world is disposed, including loads that finish late.
